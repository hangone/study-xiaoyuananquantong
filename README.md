# 校园安全教育平台辅助脚本

这是一个命令行脚本，用于登录校园安全教育平台、处理课程进度、读取本地题库并提交考试答案。脚本会根据用户选择的省份和学校使用对应的学校 ID，不再限定为江苏省院校。

## 环境要求

- Python 3
- `requests==2.31.0`
- 项目目录中的 `database.db`

可使用 `uv` 直接运行：

```bash
uv run main.py
```

也可以先安装依赖，再使用 Python 运行：

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```

## 使用流程

1. 输入学校所在省份。直接回车时默认使用江苏省；“天津”等简称会自动转换为平台使用的完整名称。
2. 输入学校名称或关键词，并在存在多个匹配项时选择学校。
3. 输入平台账号和密码。密码通过终端隐藏输入，不会显示在运行日志中。
4. 脚本登录后读取该学校的实际课程目录，并处理尚未完成的课程。
5. 课程全部完成后，脚本依次检查 `examClass=20` 和 `examClass=10` 的考试配置，使用平台返回的考试 ID 创建考试。
6. 本地题库缺题时，脚本调用 `nemotron-3-ultra-free` 生成答案并写入 `database.db`。
7. 首次提交未达到 100 分时，脚本读取平台错题反馈，校正本地答案并自动重提一次。
8. 考试达到 100 分时，脚本尝试将结课证书保存到当前项目目录。
9. 正常结束或登录后的提前退出都会尝试解除当前会话绑定。

## 实现说明

- `main.py`：登录、课程处理、考试提交和证书下载流程。
- `utils.py`：学校查询、会话接口、考试接口、本地题库和 AI 答题。
- `database.db`：题目与答案数据。

课程处理使用平台课程目录返回的实际 `courseId` 和 `articleId`。课程提交中的学习题目参数沿用该平台历史版本的通用参数；如果平台调整校验规则，课程刷新后仍显示未完成时，脚本会停止，不会继续创建考试。

## AI 答题

缺题时，脚本将题目 ID、题型、题干和选项发送到 OpenCode Zen 的 OpenAI 兼容接口：

```text
https://opencode.ai/zen/v1/chat/completions
```

使用模型为 `nemotron-3-ultra-free`，当前调用无需额外配置 API key。模型答案经过题型和选项校验后写入本地题库；考试提交后，平台错题接口返回的标准答案会覆盖对应的模型答案。

## 兼容性说明

平台接口、课程配置和题库可能随年份或学校变化。脚本会在课程未完成、考试配置不存在或本地题库缺少题目时停止并输出具体原因。不同学校的真实流程仍应以平台当前返回结果为准。
